# 2026-07-29 — Attention / charge cognitive

## Contexte

Risque de perte de visiteurs par confusion (trop de chemins) ou effort de lecture (H1 longs, pages sans repères).

## Décision

Règle `.cursor/rules/attention.mdc` : Hick (≤2 chemins), chunking, F-pattern, signal>bruit, TOC ancré, prix en évidence, prose aérée. Accueil fusionne portes + offres ; formations sans décoration lourde.

## Alternatives écartées

- Parcours personnalisé (quiz multi-écrans) : coût V1 trop élevé.
- Animations d’entrée sur toutes les sections : bruit attentionnel.

## Conséquences

SEO inchangé sur le fond (résumés, FAQ, prix HTML). Carnegie conservé (Vous, désir, écoute).
