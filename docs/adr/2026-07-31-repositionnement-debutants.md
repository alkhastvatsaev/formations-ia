# ADR — Repositionnement offres débutants + dual carrière

**Date :** 2026-07-31

## Contexte

Le site proposait une formation « IA pour développeurs » intermédiaire (RAG, agents) peu alignée avec la capacité d’enseignement actuelle et risquée pour une recherche d’emploi en parallèle (overclaim vs portfolio).

## Décision

Trois offres débutantes payantes, cherchées sur le marché :

1. `premiers-pas-ia` — ChatGPT / prompts / routine (890 €)
2. `coder-avec-ia` — Cursor / Copilot / méthode (890 €)
3. `ia-equipe-intra` — équipe TPE/PME débutante (2 400 €)

Message public : développeur qui shippe + ateliers débutants en parallèle. Redirect 301 de `/formations/ia-pour-developpeurs` → `/formations/coder-avec-ia`.

## Alternatives écartées

- Concurrencer SFEIR AI Engineer : hors crédibilité et nuisible RH.
- Uniquement ChatGPT sans angle Cursor : perd le différenciateur.

## Conséquences

SEO et blog recentrés sur intentions débutants ; articles « RAG / agents » restent informatifs avec CTA vers le premier niveau, pas vers un programme expert absent.
