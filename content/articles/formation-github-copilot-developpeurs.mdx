## Réponse directe

Se former à **GitHub Copilot**, c'est apprendre à accélérer l'écriture de code *avec* contrôle : prompts dans l'IDE, revue systématique, compréhension des suggestions incorrectes. Utile au quotidien, mais complémentaire d'une formation qui traite aussi les **API LLM** et les architectures (RAG, agents).

## Points à travailler

- Quand accepter / refuser une suggestion
- Tests et non-régression
- Données et secrets dans le contexte IDE
- Licence et propriété du code généré (politique entreprise)
