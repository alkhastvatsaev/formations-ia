## Réponse directe

**Intégrer l'IA dans une application web** suit le même esprit qu'une feature classique : besoin utilisateur, design d'API, sécurité, observabilité, tests. Le LLM est une dépendance externe non déterministe : prévoyez fallback et évaluation.

## Feuille de route courte

1. Cas d'usage et critères de succès
2. Choix modèle / fournisseur
3. Backend (clés serveur, jamais dans le front public)
4. UX (streaming, états d'erreur)
5. Eval + coûts
6. Mise en production progressive
