## Réponse directe

Un **agent IA** est un système où le modèle **décide d'appeler des outils** (fonctions, navigateurs, bases) puis réutilise le résultat pour continuer. Une formation agents IA pour développeurs montre comment construire ces boucles, les limiter, et les observer.

## Quand un agent a du sens

- Tâches multi-étapes (rechercher → calculer → rédiger)
- Besoin d'agir sur des systèmes (tickets, CRM) avec contrôle

## Quand l'éviter

- Une seule requête RAG suffit
- Coût / latence critiques sans garde-fous
- Actions irréversibles sans validation humaine
